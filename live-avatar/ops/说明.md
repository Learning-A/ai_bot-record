# 运维脚本使用说明

遇到任何问题，先跑 `检查.bat`，按报告里的箭头提示用对应脚本处理。

| 脚本 | 用途 | 什么时候用 |
|---|---|---|
| 检查.bat | 全组件体检：核心端口/页面、适配器进程与B站连接、OBS | 任何异常第一步；日常开播前也可跑一次 |
| 重启核心.bat | 只重启互动核心（danmaku_hub） | 检查显示"端口未监听/控制台不可达/总线无响应" |
| 重启适配器.bat | 只重启B站弹幕适配器 | 检查显示"适配器未运行/B站弹幕离线"；适配器进程重复 |
| 重启全部.bat | 核心+适配器按序重启 | 分不清哪个坏了，或大版本更新后 |
| 刷新OBS形象页.bat | 强制重载 OBS 里的鱼（自动发现接口密码） | 直播画面里鱼卡住/空白，但监控台正常 |
| 修复OBS场景.bat | 重建 OBS 场景（显示器采集+大肥鱼） | OBS 里场景/源丢失 |

要点：
- 脚本自动兼容两种目录布局（直播形象/ 与 avatar/），放进工具包或仓库均可用
- 核心重启后适配器会自动重连，无需手动；监控台浏览器刷新一下页面
- 适配器连不上 B 站的两大原因：Bili Live Hime 登录态失效（重新扫码）、网络波动（脚本自带退避重连，等几分钟）
- OBS 相关脚本需要 OBS 正在运行
