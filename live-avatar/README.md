# 大肥鱼直播虚拟形象 · Live Avatar

一个**平台无关**的直播虚拟形象与弹幕互动系统：透明背景的大肥鱼悬浮在直播画面上，
观众发弹幕关键词即可让它表演（吃饭/跳舞/放烟花…共 106 个动作），主播有独立监控台。

不绑定任何直播软件与弹幕平台——核心是事件总线，通过**适配器**对接具体平台，换软件不推倒重来。

## 特性

- 🐟 **106 个透明 WebM 动作**（待机/吃饭/跳舞/写代码/放烟花/撸猫…），台词气泡，开场打招呼
- 🎮 **弹幕点播**：观众发"吃饭"触发随机吃饭动作，发动作全名精确点播；全局冷却防刷屏
- 🖥️ **主播监控台**：与直播画面同步的形象、16 个免冷却动作按钮、实时弹幕流、状态灯、人气值
- 🔌 **平台无关架构**：
  - 推流软件：OBS（浏览器源，自带一键脚本）/ 任何支持色键抠像的软件（官方直播姬等，`?bg=green` 绿幕模式）
  - 弹幕平台：适配器模式，内置 B 站适配器，可自行扩展其他平台
- 📦 **纯标准库 Python + 原生 HTML/JS**，无任何依赖即可跑核心（B 站适配器可选装 brotlicffi）

## 架构

```
┌─────────────── 平台无关核心 avatar/ ────────────────┐
│ danmaku_hub.py：:8642 静态服务 + :8643 事件总线      │
│                 + 关键词引擎（弹幕→动作，冷却/去重） │
└──────▲──────────────────────────▲──────────────────┘
       │ ws                       │ 浏览器源 / 色键抠像
 danmaku_bilibili.py            推流软件（OBS/直播姬/vMix…）
 （B站弹幕适配器，可替换）
```

事件总线协议（任意语言接入）：

| 方向 | 消息 |
|---|---|
| 上报 | `{"type":"danmaku","user":"张三","text":"吃饭"}` |
| 上报 | `{"type":"cmd","text":"吃饭"}`（手动，免冷却） |
| 上报 | `{"type":"source_status","online":true,"roomid":1,"popularity":5}` |
| 广播 | `{"type":"action","name":"吃白饭","text":"吃饭","user":"张三"}` |

## 快速开始

```bash
# 1. 启动核心（无需任何直播软件，浏览器即可预览）
python avatar/danmaku_hub.py
# 打开 http://127.0.0.1:8642/console.html 看到鱼即成功

# 2. B 站弹幕适配器（可选；自动发现 Bili Live Hime 凭据，或用 --roomid/--cookies 手动指定）
python avatar/danmaku_bilibili.py

# 3. 挂到推流软件
#    OBS：python scripts/setup_obs.py 一键挂载
#    其他软件：色键模式 http://127.0.0.1:8642/index.html?bg=green + 绿幕抠像
```
