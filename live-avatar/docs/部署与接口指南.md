# 大肥鱼直播互动系统 · 开盒指南与接口文档

> 这不是"绑定某款软件"的工具包，而是一套**平台无关的直播互动系统**：
> 核心（虚拟形象 + 事件总线 + 关键词引擎）不知道任何直播软件的存在，
> 通过**适配器**对接具体的推流软件和弹幕平台。换软件 = 换/写一个适配器，核心永远复用。

---

## 一、架构：核心 + 适配器

```
                    ┌──────────── 平台无关核心（不装任何直播软件也能跑）────────────┐
                    │  danmaku_hub.py                                            │
                    │   :8642 静态服务（形象页/监控台/动画素材）                     │
                    │   :8643 事件总线 + 关键词引擎（弹幕→动作，冷却/去重）          │
                    └───────▲──────────────────────▲──────────────────────────┘
                            │ ws协议                   │ ws协议
              ┌─────────────┴────────┐      ┌────────┴─────────────────────┐
              │ 弹幕适配器（可替换）    │      │ 页面客户端（形象页/监控台）     │
              │ danmaku_bilibili.py   │      │ index.html  → 挂到推流软件     │
              │ （B站；可写其他平台）   │      │ console.html → 主播监控台     │
              └──────────────────────┘      └──────────────────────────────┘

推流软件（OBS / 官方直播姬 / vMix / 任何软件）——通过"浏览器源"或"色键抠像"挂载形象页
```

**换直播软件**：见第三节（零代码，改挂载方式）
**换弹幕平台**：见第四节（照 danmaku_bilibili.py 写一个新适配器，核心零修改）

## 二、事件总线接口协议（ws://127.0.0.1:8643）

任何语言、任何进程都能接入（浏览器 JS / Python / Node 均可）。

### 上报（你 → 核心）
| 消息 | 说明 |
|---|---|
| `{"type":"danmaku","user":"张三","text":"吃饭"}` | 一条弹幕事件（核心自动去重 3s + 关键词匹配） |
| `{"type":"cmd","text":"吃饭"}` | 手动触发（免冷却，监控台按钮用） |
| `{"type":"enter","user":"张三","vip":false}` | 观众进场（触发打招呼动作+欢迎气泡，独立冷却 8 秒） |
| `{"type":"source_status","online":true,"roomid":123,"popularity":5}` | 弹幕源状态（页面状态灯/人气值显示） |

### 广播（核心 → 所有客户端）
| 消息 | 说明 |
|---|---|
| `{"type":"action","name":"吃白饭","text":"吃饭","user":"张三"}` | 触发动作（页面播放对应动画） |
| `{"type":"danmaku","user","text","action","state":"已触发/冷却中/空"}` | 弹幕回显（监控台列表） |
| `{"type":"status","danmaku":bool,"popularity":N,"roomid":X}` | 状态同步 |

动作名即文件名：`直播形象/assets/anims/<动作名>.webm`（106 个，见第五节名单）。

### 形象页参数（index.html URL）
`?scale=1`（缩放）`?interval=40`（自动表演秒数，0=关）`?bubble=1`（台词气泡）
`?roam=1`（大画布游动）`?pool=all|classic|动作1,动作2`（动作池）
`?bg=green`（**色键模式**，见第三节）

## 三、挂载到推流软件（换软件只改这一层）

### 方式 A：浏览器源（推荐，透明背景直接叠加）
适用于支持浏览器源的软件：**OBS Studio**、vMix、Streamlabs 等。
1. 添加"浏览器源" → 本地文件 `直播形象/index.html` → 尺寸 640×360 → 放右下角
2. OBS 用户可直接跑本包 `setup_obs.py` 自动完成（OBS 适配器示例，其他软件照此思路写自动化脚本）

### 方式 B：色键抠像（任何软件都行，包括官方直播姬）
适用于只有"窗口采集 + 色键抠像"的软件：
1. 浏览器打开 `http://127.0.0.1:8642/index.html?bg=green`（需核心已运行），按 F11 全屏
2. 直播软件里添加该浏览器**窗口采集** → 对该源启用**色键抠像**，取色绿幕 → 相同色
3. 抠掉绿色后即透明叠加；鱼位置 = 浏览器窗口里鱼的位置（可加 `&scale=2` 调大小）

### 方式 C：显示器采集整屏（最简单，适合桌面直播）
浏览器把形象页开在副屏/桌面 → 显示器采集 → 鱼随桌面入镜（本页面透明背景只对浏览器源有意义，整屏采集时无影响）。

## 四、弹幕适配器：接口与参考实现

适配器 = 一个独立进程，职责单一：**把某平台的弹幕变成 `{"type":"danmaku"}` 发进总线**。

参考实现 `danmaku_bilibili.py`（B站）要点：
- 连接 B 站弹幕：TCP 2243 端口老协议 + WBI 签名 token（绕开 2024+ 的 TLS 指纹风控）
- 凭据自动发现：读 Bili Live Hime 的登录配置；也支持参数手动指定：
  `python danmaku_bilibili.py --roomid 123 --cookies cookies.json`
  （cookies.json：`{"SESSDATA":"...","bili_jct":"...","DedeUserID":"..."}`）
- 断线指数退避重连，token 每次自动刷新

**写一个新平台适配器**（斗鱼/虎牙/YouTube/Twitch…）只需三步：
1. 用任意语言连接该平台弹幕（各平台协议自行查阅，多数有开源库）
2. 每条弹幕 → WebSocket 发 `{"type":"danmaku","user":..., "text":...}` 到 `ws://127.0.0.1:8643`
3. 启动时发 `{"type":"source_status","online":true,"roomid":...}`，断开时发 `online:false`

关键词→动作的映射在核心（danmaku_hub.py 的 ALIASES），与平台无关，改一处全局生效。

## 五、部署（新电脑开盒六步）

### 第 1 步：装 Python（核心唯一硬依赖）
https://www.python.org/downloads/ 勾选 Add to PATH；再跑 `pip install brotlicffi`（B站适配器解压用，不装则自动降级）

### 第 2 步：解压本包到任意目录（中文路径 OK，别放 Program Files）

### 第 3 步：启动核心
```
python 直播形象\danmaku_hub.py
```
看到"事件总线就绪"即可。此时浏览器打开 `http://127.0.0.1:8642/console.html` 已能看到鱼（**此刻没装任何直播软件，系统已可用**）。

### 第 4 步：装推流软件（任选，见第三节挂载）
- OBS：`winget install OBSProject.OBSStudio`，然后跑本包 `setup_obs.py` 一键挂载
- 官方直播姬或其他：按"方式 B 色键"两分钟手工挂载

### 第 5 步：装弹幕适配器（任选）
- B 站：登录 Bili Live Hime（https://github.com/Rsplwe/bili-live-hime ，网关自动读它的凭据），然后 `python 直播形象\danmaku_bilibili.py`
  不想装它：浏览器 F12 抓自己直播间的 cookie 存成 JSON，用 `--cookies` 参数
- 其他平台：见第四节自己写/找人写适配器

### 第 6 步：开播验证
推流软件开推 → 监控台两个绿灯 → 点「吃饭」按钮 → 推流画面里的鱼开吃 = 成功。
日常一键启动：`启动直播工具链.bat`（核心+适配器+监控台+OBS；用别的推流软件就编辑该文件删掉 OBS 段）。

`http://127.0.0.1:8642/console.html`：同步鱼 + 16 个动作按钮（免冷却）+ 弹幕流（触发高亮）+ 状态灯（网关/弹幕源）+ 人气值。平台无关，只依赖核心。

## 八、故障排查

| 症状 | 处理 |
|---|---|
| 监控台打不开 | 核心没起：`python 直播形象\danmaku_hub.py` |
| 弹幕源灯红 | 适配器进程没起/断了：看适配器窗口日志；B站=确认凭据（Bili Live Hime 登录态或 --cookies） |
| 直播画面没鱼 | 浏览器源：眼睛点掉再点开；色键模式：检查绿幕取色与抠像开关 |
| 换了推流软件没鱼 | 按第三节重新挂载（浏览器源或色键） |
| 换了平台没弹幕 | 装对应平台适配器（第四节），核心不用动 |
| 动画素材误删 | `python 直播形象\download_anims.py` 重拉 |
