
调研结论（为什么不用你找的那两个链接的方案）：

| 方案 | 结论 |
|---|---|
| [QQ官方机器人平台](https://bot.q.qq.com/wiki/develop/api-v2/)（bot.q.qq.com） | ❌ 不满足"用我自己的QQ号"——官方机器人是**独立机器人身份**，不是你的QQ号；群里只能被@触发、主动消息受配额限制、需开发者注册审核。适合做企业服务号，不适合"我的号变成AI"。 |
| [remiliacn/qqBot](https://github.com/remiliacn/qqBot)（NoneBot2 + go-cqhttp） | ❌ 其协议端 **go-cqhttp 已于2023年底停止维护并被封杀**，现在装上大概率无法登录。它的 NoneBot2 框架层思路没问题，但协议端必须换。 |
| **NapCat + AstrBot**（本方案） | ✅ 当前社区最主流组合：NapCat（[官网](https://napneko.github.io)）是活跃维护的 NTQQ 协议端（v4.18.41，2026-10-21 更新）；[AstrBot](https://github.com/AstrBotDevs/AstrBot) 是 30k+ star 的 AI 机器人框架，[DeepSeek 官方文档直接收录了它](https://api-docs.deepseek.com/zh-cn/)，WebUI 管理、插件市场、多模型切换全都有。 |

同类替代：LangBot（也不错）、LLOneBot+NoneBot2（偏开发者）。选 AstrBot 是因为对小白最友好、生态最全。

## 1. ⚠️ 风险声明（必读）

- **NapCat 是第三方协议实现**（模拟电脑版 QQ 客户端），不是腾讯官方支持的方式。理论上存在账号被风控、限制、冻结的可能。社区大规模使用下实际风险较低，但**不为零**。
- **强烈建议用小号**当机器人，不要挂常用大号。
- 新号先正常用几天再挂机器人；别拿它刷屏、群发、发广告（默认已开限流：每会话 60 秒 30 条）。
- NapCat 占用 **PC 端登录位**：机器人号登录后，这个号就不能同时在电脑 QQ 客户端登录（互踢）；**手机端不受影响**，可同时在线。
- 继续使用 = 你已了解并接受上述风险。

**可用性三件套（2026-10-31 上线，治"聊着聊着突然没反应"）**：

- **切换**：聊天里发 `/风格` 看列表、`/风格 paopao` 或 `/风格 default` 切换、`/风格 重置` 回默认——**只影响发送者自己的会话**，每个聊天对象可以有独立风格；新聊天的人自动用默认风格（style_switcher 插件提供）
- **长期记忆已激活**（2026-10-29）：SiliconFlow 免费 bge-m3 向量模型接入后，LivingMemory 插件完整上线——机器人会自动总结聊天、记住你的偏好和约定，越聊越懂你；同款 embedding 也让 AstrBot 知识库功能可用（WebUI → 知识库）
- **记忆按人刚性隔离**（2026-10-29 补强）：`memory_scope_mode=session`（对齐 Mem0 的 per-user 命名空间隔离标准）——每个聊天对象只能召回自己的记忆，互相绝不串（换人格记忆跟人走）。跨会话共享如需开启（同一人私聊+群聊记忆合并）改 `user` 模式即可
- **四层记忆架构**（2026-10-29 定稿，对标 Mem0/Letta/MemOS 社区最佳实践）：
  - **L1 工作记忆**：当前会话上下文（AstrBot 原生，24 轮自动压缩）——"正在聊什么"
  - **L2 短期情景记忆**：LivingMemory 逐条对话流水 + 情景原子（TTL 7 天自动遗忘）——"最近发生过什么"
  - **L3 长期语义记忆**：事实原子 + 知识图谱 + 重要性衰减遗忘（TTL 180 天）+ AI 主动读写工具——"长期知道什么"
  - **L4 核心记忆**（core_memory 插件，自研）：自我认知卡（全局）+ 主人档案卡（按人隔离），**每轮对话永远注入、不靠检索、AI 随时自编辑**（Letta core memory block 模式）——"我是谁/他是谁"；`/核心记忆` 查看与清理
  - 层间流转：L1 满自动压缩；L2→L3 由 LivingMemory 反思引擎按 10 轮阈值自动提炼；L3→L4 由 AI 判断"值得永远记住"时主动调用工具升级；L2/L3 按遗忘曲线衰减，L4 永不遗忘

- 改档案/样本：WebUI → 人格情境（系统提示词=档案；开场对话=样本，**必须成对偶数条**）
- 调整拆分/延迟：WebUI → 配置 → 分段回复

### 5.8 安全护栏 ✅（2026-10-30 v15 上线，safety_guard 插件）

## 6. 常见问题 FAQ

**Q1：NapCat 窗口报 QQ 版本不兼容 / 闪退？**
本机 QQ 是 9.9.36，NapCat 4.18.41 内置适配 9.9.22，通常兼容但有小概率抽风。解法：解压 `downloads\NapCat.OneKey.zip`，运行 `NapCatInstaller.exe`——它会自动装一份 NapCat 适配的 QQ 到独立目录（不影响你现有的 QQ），之后用它生成的目录里的 `napcat.bat` 启动（把启动脚本里 NapCat 路径换成它）。

**Q2：扫码后手机提示"环境异常/账号冻结"？**
被风控了。手机号验证解冻 → 换个号 → 降低使用频率，别群发广告。

**Q3：机器人不回话？按顺序排查：**
1. AstrBot WebUI「日志」有没有收到消息？没有 → NapCat 反向 WS 没连上（重做第 3 步）
2. 日志报 401 / invalid key → DeepSeek API Key 没填对（重做第 1 步）
3. 收到消息也调用了模型但没发出去 → 看 NapCat WebUI 日志是否风控（发送失败）

**Q4：QQ 自动更新后机器人挂了？**
电脑 QQ 设置里关掉自动更新；NapCat 一般几天内跟进适配，去 [NapCat Releases](https://github.com/NapNeko/NapCatQQ/releases) 下最新 `NapCat.Shell.zip` 覆盖 `NapCat.Shell\` 即可。

**Q5：怎么更新 AstrBot？**
命令行执行：`uv tool upgrade astrbot --python 3.12`

**Q6：想开机自启？**
`Win+R` 输 `shell:startup`，把 `启动QQ机器人.bat` 的快捷方式丢进去。

**Q7：日志在哪？**
AstrBot：`astrbot\data\logs\`；NapCat：黑窗口实时输出 + `NapCat.Shell\logs\`。
